## 1. Summary (under 200 words)
TwoToe is a local tool that does breach-week triage overnight. At 7 a.m. it gives you two lines plus a checklist of at most 7 items. Code collects the facts: the probe and scanners build an inventory, and a deterministic matcher turns it into findings with a confidence tier. Local Gemma (via Ollama) only phrases those findings. A validator rejects any token the matcher did not establish, and a template writer is always available as a fallback.

**Hard rules:**
- Env key names only, never values. The canary must never appear in output.
- IOC files get stat and SHA-256 only, never opened or run.
- No installs and no user code during a scan. execFile with argument arrays and 5s timeouts.
- Network goes through an allowlist: loopback, cisa.gov, and Sentry only if you opt in.
- Defensive only.
- Demos and eval use fixtures only, and home paths are redacted to `~`.
- Never edit `expected.json` to make metrics pass.
- Pack facts must come from sources I actually fetched.

**Phases:** 0 scaffold and pack, 1 probe and scanners, 2 matcher and `brief --no-llm`, 3 writer, validator and egress guard, 4 Temporal, 5 card, 6 eval, 7 Sentry, 8 post, 9 stretch. Each phase ends at a gate.
